Adds items and mechanics from from SS13/14 to Probably Stolen.

This is the repository for mod development. If you're looking for a download, go here: https://www.nexusmods.com/probablystolen/mods/375?tab=files
If you've encountered a bug, feel free to report it as an issue here: https://github.com/TheSecondLord/probablynuclear/issues
If you'd like to make a suggestion, feel free to leave it as a comment on this thread in the Probably Nuclear discord server: https://discord.com/channels/1315752321975845004/1554966551956815903
If you'd like to add a translation for another language, please either create a PR to add it under Localization/[language code].csv or reach out to me directly on the thread above.

You are allowed and encouraged to use this code as example material for creating your own mod if you would like, although I ask that you please don't copy art assets or redistribute the mod wholesale.
If you do reuse this code for your own mod, credit is appreciated.
